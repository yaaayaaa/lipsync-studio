# zunda-lipsync

PSD の立ち絵を VOICEVOX の音声にリップシンクさせ、mp4 として書き出すブラウザアプリです。
PSD・セリフ・音声は外部に送信しません。通信するのは、設定した VOICEVOX エンジンの URL だけです。

## 必要なもの

- [VOICEVOX](https://voicevox.hiroshiba.jp/)（エンジンを起動しておく。既定の URL は `http://localhost:50021`）
- Node.js
- Chrome または Edge のデスクトップ版（Windows / macOS）

## 起動手順

1. `npm install`
2. VOICEVOX を起動する
3. `npm run dev`

別の端末など、`localhost` 以外の URL でこのアプリを開く場合は、その URL（オリジン）を VOICEVOX 側で許可する必要があります。
`http://localhost:50021/setting` を開き、許可するオリジンに追加してください。

## 使い方

画面は左のメニューで切り替えます（「キャラ設定」「セリフ」「1行編集」と、一番下の「設定」）。メニューは左上のボタンでアイコンだけにたためます。

1. **キャラ追加**：「キャラ設定」で立ち絵の .psd を追加する。レイヤーツリーで表示を切り替えられる
2. **口グループと母音の割り当て**：口のレイヤーが入ったグループを選び、あ・い・う・え・お・閉じ にそれぞれ口を割り当てる。「あいうえお」で試し再生できる。声（話者）もここで選ぶ
3. **スタイル**：今の表示状態をスタイルとして保存する。PSDTool の .pfv も取り込める
4. **セリフ**：「セリフ」でセリフを追加し、キャラ・スタイル・話速（0.5〜2.0）を選ぶ。試聴とプレビューができる
5. **書き出し**：1行ずつ、または全行をまとめて（zip）書き出す。H.264 + AAC、30fps の mp4 になる。背景は単色で、既定は `#00FF00`（動画編集ソフトのクロマキー用）
6. **設定**：VOICEVOX エンジンの URL と、書き出しの解像度・立ち絵の大きさ・背景色を「設定」で変える。エンジンにつながらないときは画面上部に案内が出る

### 1行編集

「セリフ」の行のメニューから「1行編集で開く」を選ぶと、VOICEVOX エディタのように 1 行ずつ声を作り込めます。
再生は口パク付きで確かめられます。

- **アクセント**：モーラをクリックして下がる位置を変える。モーラの間で句を区切り、境目のボタンでつなぐ。読み（カタカナ）も直せる
- **高さ・長さ**：モーラごとの高さ、子音・母音の長さ、句の後ろの無音を変える
- **全体の数値**：話速・音高・抑揚・音量・間の倍率・開始と終了の無音。話速は「セリフ」の話速と同じ値
- 取り消し（Ctrl/Cmd+Z）・やり直し（Ctrl/Cmd+Shift+Z、Ctrl+Y）と、作り込みを捨てる「元に戻す」がある。履歴は 1 行編集での編集だけが対象で、「セリフ」の画面でその行を変えると、その行の履歴は消える
- 作り込みは行ごとに保存される。**セリフの文を変えて確定すると、作り込みは捨てられる**（確認が出る）。声（スタイル）を変えたときは、アクセントはそのままで高さと長さだけを取り直す。確定しないまま文と作り込みが食い違って残ったとき（打っている途中で再読み込みしたなど）は、行に出る知らせから「作り込みを捨てる」か「文を戻す」を選ぶ
- 「この行を書き出し」の mp4 は `セリフ先頭10文字_ID8文字.mp4` の名前でダウンロードされる。ID は書き出すたびに変わる。zip の中の名前（`001_キャラ名_…`）は変わらない

PSD 以外の素材は不要です。試すだけなら、`npx tsx scripts/make-sample-psd.ts` でサンプル PSD（`samples/sample.psd`、git 管理外）を作れます。

画面の配色は OS のライト / ダーク設定に従います（書き出す動画の色には影響しません）。

## VOICEVOX のクレジット表記

VOICEVOX で作った音声を公開するときは、クレジット表記が必要です。
書き出し後に `VOICEVOX:キャラ名` の形で表示されるので、動画の概要欄などに記載してください。
話者ごとの利用規約は、利用者自身が確認し、守ってください。

## 開発用コマンド

- `npm test` : テストを実行する
- `npm run typecheck` : 型チェック
- `npm run lint` : oxlint
- `npm run build` : 本番ビルド
- `npx tsx scripts/make-sample-psd.ts` : サンプル PSD の生成
- `npx tsx scripts/check-timeline.ts` : 口パクのタイムライン（1行編集で手を加えたクエリを含む）を本物のエンジンで照合する
