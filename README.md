# lipsync-studio（リップシンクスタジオ）

PSD の立ち絵を VOICEVOX の音声にリップシンクさせ、mp4 として書き出すデスクトップアプリです（Mac / Windows）。
PSD・セリフ・音声は外部に送信しません。通信するのは、設定した VOICEVOX エンジンの URL と、更新の確認とダウンロードのための GitHub（このリポジトリの Releases）だけです。

## 必要なもの

- macOS（Apple シリコン / Intel）または Windows 10 / 11（64 ビット）
- [VOICEVOX](https://voicevox.hiroshiba.jp/)（使うときにエンジンを起動しておく。既定の URL は `http://localhost:50021`）

## 入れ方

[Releases](https://github.com/yaaayaaa/lipsync-studio/releases/latest) から、使うパソコンに合うファイルをダウンロードします。

- **Mac（Apple シリコン）**：`lipsync-studio-<版>-arm64.dmg`
- **Mac（Intel）**：`lipsync-studio-<版>.dmg`
- **Windows**：`lipsync-studio-Setup-<版>.exe`

Mac は dmg を開き、`lipsync-studio` を「アプリケーション」フォルダにドラッグします。初めて開くときに「インターネットからダウンロードされたアプリケーションです。開いてもよろしいですか?」と聞かれたら「開く」を選びます。

Windows はインストーラーを実行します。署名していないため「Windows によって PC が保護されました」（SmartScreen）と出たら、「詳細情報」を押してから「実行」を押します。インストーラーは何も聞かずに、使っているユーザーだけに入れて（管理者の権限は要りません）、終わるとアプリを開きます。

## 起動手順

1. VOICEVOX を起動する
2. lipsync-studio を開く

更新は自動です。新しい版が出ていると裏でダウンロードし、次にアプリを終了したときに入れ替わります（知らせは出ません）。

## 使い方

画面は左のメニューで切り替えます（「台本」「キャラ設定」と、一番下の「設定」）。開くと台本から始まります（キャラがまだいないときはキャラ設定から）。メニューは左上のボタンでアイコンだけにたためます。

1. **キャラ追加**：「キャラ設定」で立ち絵の .psd を追加する。レイヤーツリーで表示を切り替えられる
2. **口グループと母音の割り当て**：口のレイヤーが入ったグループを選び、あ・い・う・え・お・閉じ にそれぞれ口を割り当てる。「あいうえお」で試し再生できる。声（話者）もここで選ぶ
3. **スタイル**：今の表示状態をスタイルとして保存する。PSDTool の .pfv も取り込める
4. **目の割り当て（瞬き）**：「キャラ設定」で目のグループ（口とは別のグループ）と閉じ目を選ぶ（半目は任意）。「瞬き」ボタンで見た目を確かめられる。割り当てると、プレビューと書き出しで 1〜3 秒後から 3〜5 秒おきに瞬きする（動画の終わりで途中で切れてしまう瞬きは入れない）。瞬きの位置は行ごとに決まっていて、書き出しのたびには変わらない。割り当てなければ瞬きしない。「目（瞬き）」の見出しの横のスイッチをオフにすると、割り当てを残したまま瞬きだけ止められる（オフの間は欄が畳まれる）
5. **台本**：「台本」の「行を追加」でセリフを足し、1 行ずつ声を作り込んで書き出す（下の「台本」を参照）
6. **終端の長さ**：声が終わったあとに口を閉じたまま足す秒数（0〜10 秒、音声には無音を足さない）。「設定」の既定が全行に効き、「台本」の「その他」の「終端」で行ごとに変えられる（「既定に戻す」で既定に従う）。プレビューには足さない
7. **設定**：VOICEVOX エンジンの URL と、書き出しの解像度・立ち絵の大きさ・終端の長さ・背景色を「設定」で変える。解像度は 1920×1080・1280×720・1080×1920（縦）・1080×1080（正方形）から選ぶか、「カスタム」で幅と高さ（16〜3840 の偶数）を入れる。カスタムは、そのパソコンで書き出せる大きさかを確かめてから保存する。エンジンにつながらないときは画面上部に案内が出る。「表示」で明暗（OS の設定に合わせる／ライト／ダーク）と、台本のパネルの並びを初めに戻す操作がある。明暗はこのパソコンにだけ覚える

### 台本

左の一覧で行を選び、VOICEVOX エディタのように 1 行ずつ声を作り込めます。パネルはタブのドラッグで並べ替えられ、並びはこのパソコンに覚えます。
「行を追加」を押すと、新しい行のセリフ欄にカーソルが入ります。行を右クリックすると、上下への追加・複製・移動・削除ができます。ドラッグか Alt+↑↓ でも並べ替えられます。

- **セリフ**：文の欄。文を変えると、その行の作り込みは捨てられる（取り消しで文ごと戻せる）
- **プレビュー**：口パク付きで再生する。Space で再生・停止を切り替えられる（動画編集ソフトと同じ）。文の欄で打っている間は空白が入る
- **アクセント**：モーラをクリックして下がる位置を変える。モーラの間で句を区切り、境目のボタンでつなぐ。読み（カタカナ）も直せる
- **高さ・長さ**：モーラごとの高さ、子音・母音の長さ、句の後ろの無音を変える
- **その他**：キャラ・スタイル、声、話速（0.5〜2.0）・音高・抑揚・音量・間の倍率・開始と終了の無音、終端。声は選ばなければ「デフォルト」（キャラ設定の声）で、選ぶとその行だけの声になる
- 取り消し（Ctrl/Cmd+Z）・やり直し（Ctrl/Cmd+Shift+Z、Ctrl+Y）と、作り込みを捨てる「元に戻す」がある
- 作り込みは行ごとに保存される。声（スタイル）を変えたときは、アクセントはそのままで高さと長さだけを取り直す
- **書き出し**：「この行を書き出し」で、その行を H.264 + AAC、30fps の mp4 にする。背景は単色で、既定は `#00FF00`（動画編集ソフトのクロマキー用）。ファイル名は `セリフ先頭10文字_ID8文字.mp4` で、ID は書き出すたびに変わる
- **まとめて書き出し**：セリフ一覧の一番下のボタンから、「1つの mp4 にまとめる」（`lipsync-studio.mp4`。行を台本の順に、各行の終端も含めてつなぐ）か「セリフごとの mp4 を zip で」（`lipsync-studio.zip`。中の名前は `001_キャラ名_本文先頭10文字.mp4` で、番号は台本の行番号）を選ぶ。キャラ・声・口・文のどれかが足りない行は飛ばし、終わったあとに何行目を飛ばしたかを出す。zip では途中で失敗した行を除いて残りを入れ、1つの mp4 では失敗した行で止める

PSD 以外の素材は不要です。試すだけなら、`npx tsx scripts/make-sample-psd.ts` でサンプル PSD（`samples/sample.psd`、git 管理外）を作れます。

画面の配色は OS のライト / ダーク設定に従います（書き出す動画の色には影響しません）。

## VOICEVOX のクレジット表記

VOICEVOX で作った音声を公開するときは、クレジット表記が必要です。
使った話者ごとに `VOICEVOX:話者名` の形で、動画の概要欄などに記載してください（アプリは表記を出しません）。
話者ごとの利用規約は、利用者自身が確認し、守ってください。

## 開発

Node.js が要ります。

1. `npm install`
2. `npm run dev` で画面の開発サーバーを起動し、別の端末で `npm run electron:dev` を実行すると、その画面をデスクトップアプリの窓で開く

- `npm test` : テストを実行する
- `npm run typecheck` : 型チェック
- `npm run lint` : oxlint
- `npm run build` : 画面の本番ビルド
- `npm run electron:start` : 画面と main を本番ビルドしてデスクトップアプリで開く
- `npm run dist:mac` / `npm run dist:win` : 配布物を `release/` に作る（Mac は署名と公証の鍵が要る。`scripts/dist-mac.sh` を参照）
- `npx tsx scripts/make-sample-psd.ts` : サンプル PSD の生成
- `npx tsx scripts/check-timeline.ts` : 口パクのタイムライン（1行編集で手を加えたクエリを含む）を本物のエンジンで照合する

Electron の本体は `electron` コマンドを初めて使うときに落ちてきます。`node_modules/electron/dist/` の中を直接起動するスクリプト（Playwright の `_electron.launch` など）を先に使うときは、`npx install-electron` を一度実行してください。
`npm run dev` の画面をブラウザで直接開くときだけは、VOICEVOX エンジンの `/setting` で開発サーバーのオリジン（`http://localhost:5173`）を許可する必要があります（デスクトップアプリではエンジンとの通信をアプリ本体が行うので要りません）。
