# zunda-lipsync

PSD の立ち絵を VOICEVOX の音声にリップシンクさせ、mp4 として書き出すブラウザアプリです。
PSD・セリフ・音声は外部に送信しません。通信するのは、設定した VOICEVOX エンジンの URL だけです。

## 必要なもの

- [VOICEVOX](https://voicevox.hiroshiba.jp/)（エンジンを起動しておく。既定の URL は `http://localhost:50021`）
- Node.js
- Chrome または Edge のデスクトップ版（Windows / macOS）

## 起動手順

1. `npm install`
2. VOICEVOX を起動する
3. `npm run dev`

別の端末など、`localhost` 以外の URL でこのアプリを開く場合は、その URL（オリジン）を VOICEVOX 側で許可する必要があります。
`http://localhost:50021/setting` を開き、許可するオリジンに追加してください。

## 使い方

画面は左のメニューで切り替えます（「キャラ設定」「台本」と、一番下の「設定」）。メニューは左上のボタンでアイコンだけにたためます。

1. **キャラ追加**：「キャラ設定」で立ち絵の .psd を追加する。レイヤーツリーで表示を切り替えられる
2. **口グループと母音の割り当て**：口のレイヤーが入ったグループを選び、あ・い・う・え・お・閉じ にそれぞれ口を割り当てる。「あいうえお」で試し再生できる。声（話者）もここで選ぶ
3. **スタイル**：今の表示状態をスタイルとして保存する。PSDTool の .pfv も取り込める
4. **目の割り当て（瞬き）**：「キャラ設定」で目のグループ（口とは別のグループ）と閉じ目を選ぶ（半目は任意）。「瞬き」ボタンで見た目を確かめられる。割り当てると、プレビューと書き出しで 1〜3 秒後から 3〜5 秒おきに瞬きする（動画の終わりで途中で切れてしまう瞬きは入れない）。瞬きの位置は行ごとに決まっていて、書き出しのたびには変わらない。割り当てなければ瞬きしない。「目（瞬き）」の見出しの横のスイッチをオフにすると、割り当てを残したまま瞬きだけ止められる（オフの間は欄が畳まれる）
5. **台本**：「台本」の「行を追加」でセリフを足し、1 行ずつ声を作り込んで書き出す（下の「台本」を参照）
6. **終端の長さ**：声が終わったあとに口を閉じたまま足す秒数（0〜10 秒、音声には無音を足さない）。「設定」の既定が全行に効き、「台本」の「その他」の「終端」で行ごとに変えられる（「既定に戻す」で既定に従う）。プレビューには足さない
7. **設定**：VOICEVOX エンジンの URL と、書き出しの解像度・立ち絵の大きさ・終端の長さ・背景色を「設定」で変える。エンジンにつながらないときは画面上部に案内が出る。「表示」で明暗（OS の設定に合わせる／ライト／ダーク）と、台本のパネルの並びを初めに戻す操作がある。明暗はこのブラウザにだけ覚える

### 台本

左の一覧で行を選び、VOICEVOX エディタのように 1 行ずつ声を作り込めます。パネルはタブのドラッグで並べ替えられ、並びはこのブラウザに覚えます。
「行を追加」を押すと、新しい行のセリフ欄にカーソルが入ります。行を右クリックすると、上下への追加・複製・移動・削除ができます。ドラッグか Alt+↑↓ でも並べ替えられます。

- **セリフ**：文の欄。文を変えると、その行の作り込みは捨てられる（取り消しで文ごと戻せる）
- **プレビュー**：口パク付きで再生する。Space で再生・停止を切り替えられる（動画編集ソフトと同じ）。文の欄で打っている間は空白が入る
- **アクセント**：モーラをクリックして下がる位置を変える。モーラの間で句を区切り、境目のボタンでつなぐ。読み（カタカナ）も直せる
- **高さ・長さ**：モーラごとの高さ、子音・母音の長さ、句の後ろの無音を変える
- **その他**：キャラ・スタイル、声、話速（0.5〜2.0）・音高・抑揚・音量・間の倍率・開始と終了の無音、終端。声は選ばなければ「デフォルト」（キャラ設定の声）で、選ぶとその行だけの声になる
- 取り消し（Ctrl/Cmd+Z）・やり直し（Ctrl/Cmd+Shift+Z、Ctrl+Y）と、作り込みを捨てる「元に戻す」がある
- 作り込みは行ごとに保存される。声（スタイル）を変えたときは、アクセントはそのままで高さと長さだけを取り直す
- **書き出し**：「この行を書き出し」で、その行を H.264 + AAC、30fps の mp4 にする。背景は単色で、既定は `#00FF00`（動画編集ソフトのクロマキー用）。ファイル名は `セリフ先頭10文字_ID8文字.mp4` で、ID は書き出すたびに変わる
- **まとめて書き出し**：セリフ一覧の一番下のボタンから、「1つの mp4 にまとめる」（`zunda-lipsync.mp4`。行を台本の順に、各行の終端も含めてつなぐ）か「セリフごとの mp4 を zip で」（`zunda-lipsync.zip`。中の名前は `001_キャラ名_本文先頭10文字.mp4` で、番号は台本の行番号）を選ぶ。キャラ・声・口・文のどれかが足りない行は飛ばし、終わったあとに何行目を飛ばしたかを出す。zip では途中で失敗した行を除いて残りを入れ、1つの mp4 では失敗した行で止める

PSD 以外の素材は不要です。試すだけなら、`npx tsx scripts/make-sample-psd.ts` でサンプル PSD（`samples/sample.psd`、git 管理外）を作れます。

画面の配色は OS のライト / ダーク設定に従います（書き出す動画の色には影響しません）。

## VOICEVOX のクレジット表記

VOICEVOX で作った音声を公開するときは、クレジット表記が必要です。
使った話者ごとに `VOICEVOX:話者名` の形で、動画の概要欄などに記載してください（アプリは表記を出しません）。
話者ごとの利用規約は、利用者自身が確認し、守ってください。

## 開発用コマンド

- `npm test` : テストを実行する
- `npm run typecheck` : 型チェック
- `npm run lint` : oxlint
- `npm run build` : 本番ビルド
- `npx tsx scripts/make-sample-psd.ts` : サンプル PSD の生成
- `npx tsx scripts/check-timeline.ts` : 口パクのタイムライン（1行編集で手を加えたクエリを含む）を本物のエンジンで照合する
