## 既知の制限

- 合成した音声は（セリフ・声・話速）ごとにページを開いている間だけ覚えて使い回す（上限 64MB）。VOICEVOX 側でユーザー辞書を変えたときは、ページを再読み込みするまで古い読みのまま
- レイヤーマスクは未対応
- クリッピングされたレイヤーは、自分自身の描画モードを無視する（例：乗算の影が通常描画になる）
- 未対応の描画モードのレイヤーは、通常描画になる
- 口が複数のグループに分かれている PSD は未対応
- Linux 版 Chrome は対象外（AAC をエンコードできないため）。実行時に `canEncodeAudio` で判定し、非対応なら画面に表示する
- 「キャラ設定」で「あいうえお」を再生中に「セリフ」タブへ切り替えても、再生は約2秒で終わるまで止まらない（両方の画面を表示したまま保持しているため）
- 書き出した mp4 の音声末尾に、約 40 ms の無音（AAC のパディング）が動画の終わりより後ろにはみ出ることがある
- タブを閉じる直前 300 ms 以内の編集は、保存されないことがある
- サムネイルの範囲検出は縮小コピーで行うため、非常に大きなレイヤー（約2800px超）の孤立した微小な点は切り抜き範囲から外れることがある
- サムネイルはグループ・レイヤーの不透明度と描画モードを反映しない（グループは中身を合成したもの、レイヤーは画像そのものを出す）
