# 終端の長さと瞬き 設計書

- 日付: 2026-10-20
- 状態: 初版
- 前提: [zunda-lipsync 設計書](2026-10-19-zunda-lipsync-design.md)、[1行編集画面 設計書](2026-10-20-line-editor-design.md) の上に足す機能。矛盾したときはこちらを優先する

## 1. 何を作るか・なぜ作るか

書き出した1行ずつの mp4 を動画編集ソフトに並べると、セリフとセリフの間で立ち絵が消えて不自然になる（ユーザーの指摘）。

隙間を埋める仕組み（長い待機クリップを敷く、全行を1本につなぐ等）も検討したが、アプリが複雑になるので見送った（ユーザー決定：「今のままでいこう」）。代わりに次の2つを足す（ユーザー決定）。

1. **終端の長さ**：喋り終わったあとも、立ち絵を指定の秒数だけ映し続ける。次のセリフを重ねて置けば隙間が埋まる
2. **瞬き**：立ち絵がときどき瞬きする。喋っていない間（終端の部分）が止め絵にならないようにする

喋っていない間の立ち絵は「基本デフォルト状態で、瞬きだけ」（ユーザーの言葉）。

## 2. 目的・目的外・避けたいこと

### 目的

- 終端の長さの既定値を設定画面で決められる（ユーザー決定）
- 必要な行だけ、1行編集の画面で終端の長さを変えられる（ユーザー決定）
- 目を割り当てたキャラは、書き出した動画で瞬きする

### 目的外（今回はやらない）

- 隙間を自動で埋める仕組み（待機クリップ・全行を1本につなぐ書き出し・透過動画）。ユーザー決定で見送り
- 喋っていない間の別の動き（体の揺れ・呼吸など）
- 瞬きの間隔をユーザーが調整する UI（私の判断。必要になったら足す）
- スタイルごとに瞬きを止める設定（私の判断。5.4 節の既知の制限）

### 避けたいこと

- 設定を足したことで、今までの書き出し結果が勝手に変わる（既存ユーザーは終端 0 秒・瞬きなしのまま）
- 同じ行を書き出し直すたびに瞬きの位置が変わり、編集ソフトで差し替えたときに映像がずれる
- 瞬きと口パクがぶつかって、どちらかが崩れる
- 書き出しが目に見えて遅くなる

## 3. 終端の長さ

### 3.1 中身

- 「喋り終わり」は今の動画の終わり（音声の長さとタイムラインの長さの長いほう）。そこから終端の長さだけ動画を延ばす
- 延ばした部分の立ち絵は、口を閉じた状態（`closed` の口）で、瞬きする（4 節）。顔・服などはその行のスタイルのまま
- 延ばした部分に音は入れない。音声トラックは今のまま（私の判断。音声は喋り終わりで終わり、映像だけが続く。編集ソフトはこれを普通に扱える）
- 範囲は 0〜10 秒、0.1 秒刻み（私の判断）。フレーム数への丸めは今の `frameSchedule` と同じ考え方（切り上げ）

### 3.2 既定値と行ごとの値

- 設定画面の「書き出し」欄に「終端の長さ」を足す。これが既定値。初期値は 0 秒（私の判断。今までの書き出しと同じ結果になる）
- `ExportSettings` に持たせる（保存先は今の設定と同じ IndexedDB。古い保存データは 0 秒として読む）
- 行は終端の長さを任意で持てる（`ScriptLine` に任意の項目を足す）。持っていない行は既定値を使う
- 1行編集の画面の右側（全体の数値の欄）に「終端の長さ」を置く（ユーザー決定）
  - 行が自分の値を持っていなければ、既定値を表示する。動かした時点でその行の値になる
  - 行が自分の値を持っているときは「既定に戻す」で、その行の値を消して既定値に戻せる（私の判断）
  - 自分の値を持っているかどうかが分かる表示にする（私の判断。既定値を変えても、その行は変わらないため）
  - この変更も1行編集の取り消し（Ctrl/Cmd+Z）の対象にする（私の判断。他の編集と同じ扱い）
- 「セリフ」画面の一覧には出さない（私の判断。行ごとに変えるのは例外的な使い方で、一覧の列を増やしたくない）
- 終端の長さは声の作り込み（`tuning`）とは別の項目にする。文を変えて作り込みが捨てられても、終端の長さは残る

### 3.3 効く場所

- 書き出し：セリフ画面の1行ずつの書き出し、全行の書き出し（zip）、1行編集の「この行を書き出し」のすべてに効く
- アプリ内の試聴・プレビュー再生には効かせない。喋り終わったら今までどおり止まる（私の判断。確かめたいのは声と口なので、毎回待たされないほうがよい）

## 4. 瞬き

### 4.1 キャラ設定での割り当て

口と同じやり方にする。

- 「目のグループ」を選ぶ。表示するレイヤーを1つ選ぶ形のグループ（PSDTool の `*` の子を持つグループ）を選ぶ想定
- そのグループの中から「閉じ目」のレイヤーを割り当てる。必須
- 「半目」のレイヤーも割り当てられる。任意（私の判断。あるとなめらかになるが、ずんだもん立ち絵素材 2.3 のように半目がない PSD もある）
- 開いた目は割り当てない。その行のスタイルで表示している目をそのまま使う（私の判断。スタイルで目線や目の形を変えても、それが開いた目になる）
- 閉じ目を割り当てていないキャラは瞬きしない（今までと同じ）
- 割り当ては、口の割り当てと同じくキャラに保存する。古い保存データ（目の割り当てなし）はそのまま読める

参考：ずんだもん立ち絵素材 2.3（坂本アヒル）の PSD では、`!目` グループの子に `*目セット`（開いた目のグループ）、`*UU`（閉じ目）、`*にっこり` などが並ぶ。目のグループに `!目`、閉じ目に `*UU` を選ぶ使い方になる。

### 4.2 瞬きの見せ方

- 瞬きの間は、目のグループの子を全部消して、閉じ目（または半目）のレイヤーだけを表示する。口の切り替え（`applyMouth`）と同じ考え方
- 1回の瞬き（30fps のフレーム単位、私の判断）
  - 半目あり：半目 1 → 閉じ 2 → 半目 1（約 0.13 秒）
  - 半目なし：閉じ 3（0.1 秒）
- 瞬きと瞬きの間は 3〜5 秒のばらつき（私の判断。人の平均的な瞬きの間隔に合わせた）。動画の頭は、最初の瞬きまで 1〜3 秒空ける（私の判断。頭でいきなり目を閉じないように）
- 喋っている間も瞬きする（私の判断。人は話しながら瞬きする。目と口は別のグループなので、ぶつからない）

### 4.3 同じ行は同じ瞬き

- 瞬きの位置は、その行から決まる値（行の ID など）をもとにした擬似乱数で決める（私の判断）。同じ行を書き出し直しても、同じ位置で瞬きする
- 行ごとに違う位置にはなるので、全部の行が同じ秒数で瞬きすることはない
- 終端の長さを変えても、それより前の瞬きの位置は変わらない（延ばした部分に瞬きが足されるだけ）

### 4.4 効く場所

- 書き出し（3.3 節と同じ3か所）
- アプリ内のプレビュー再生（セリフ画面・1行編集）でも瞬きする（私の判断。書き出す前に見た目を確かめられるように）
- キャラ設定のプレビューに、1回瞬きして見せるボタンを置く（私の判断。割り当てを確かめるため）

## 5. 気をつけること

### 5.1 書き出しの速さ

今は口の形ごとに立ち絵を先に合成して使い回している（`prerenderMouthFrames`）。瞬きが入ると「口 × 目（開き・半目・閉じ）」の組み合わせになる。先に全部合成するか、使うときに合成して覚えておくかは作る人に任せるが、書き出しの時間が今と比べて目に見えて延びないこと。

### 5.2 リップシンク

口のタイムラインは今のまま（`buildMouthTimeline`）。瞬きは口と独立に、フレームごとの目の状態として足す。音と口のずれが出ないことは今の照合（`scripts/check-timeline.ts`）で引き続き確かめられる。

### 5.3 動画の長さ

動画の長さ = 喋り終わりまで（今と同じ）＋終端の長さ。音声トラックの長さは今と変わらない。

### 5.4 既知の制限として残すもの

- 「にっこり」のように、スタイルで初めから目を閉じた形にしている行も、瞬きの間は割り当てた閉じ目に切り替わる（ユーザーに確認したうえで、今回は気にしない）
- 目のグループが口のグループと同じ・目のグループの中に口がある、といった割り当ては想定しない。選べないようにするか、選んだら知らせるかは作る人に任せる

## 6. 作る人に任せること

- キャラ設定の画面で、目の割り当てを口の欄の近くにどう並べるか
- 1行編集の右側で「終端の長さ」をどこに置くか（全体の数値と同じ欄か、別の欄か）。行が自分の値を持っているかの表示の仕方
- 擬似乱数の作り方（行から決まって、同じ入力なら同じ結果になること）
- 立ち絵の合成を先にするか、使うときにするか（5.1 節）

## 7. テスト方針

- 終端の長さ：フレーム数（0 秒で今と同じ、0.1 秒刻みの切り上げ）、延ばした部分が閉じた口であること、行の値があればそれを、なければ既定値を使うこと
- 古い保存データ（終端の長さ・目の割り当てを持たない設定・キャラ・行）を読めること
- 瞬き：同じ行なら同じ位置、間隔が 3〜5 秒に収まる、頭の 1 秒は瞬きしない、半目のあり・なしでの並び、閉じ目が未割り当てなら瞬きしない
- 目の状態の当て方：目のグループの子を全部消して指定のレイヤーだけ出す（口の当て方と同じ形のテスト）
- 書き出し全体：終端の長さ 0 秒・瞬きなしのキャラで、今までと同じフレーム数と同じ見た目になること
- 1行編集での終端の長さの変更・既定に戻す・取り消し
